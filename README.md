# 📝 مفكرة المهام اليومية (Django To-Do App)

تطبيق ويب متكامل لإدارة المهام اليومية، تم تطويره باستخدام إطار عمل **Django** ولغة **Python**. المشروع يهدف إلى توفير واجهة بسيطة وسريعة للمستخدم لإضافة، إنجاز، وحذف المهام بكل سهولة.

## ✨ المميزات (Features)
* **إضافة مهام جديدة:** واجهة سهلة وسريعة لإدخال المهام.
* **تتبع الإنجاز:** إمكانية تحديد المهام المكتملة (يتم شطبها بخط لتوضيح إنجازها) مع إمكانية التراجع.
* **حذف المهام:** زر مخصص لحذف المهام التي لم تعد مطلوبة بضغطة واحدة.
* **تصميم متجاوب:** واجهة مستخدم نظيفة ومنسقة باستخدام HTML/CSS المدمج.

## 🛠️ التقنيات المستخدمة (Technologies)
* **Back-end:** Python, Django 5.x
* **Front-end:** HTML5, CSS3
* **Database:** SQLite (Default Django DB)
